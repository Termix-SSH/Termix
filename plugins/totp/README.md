<h1>TOTP</h1>

<p>Two-factor sign in with an authenticator app</p>

</div>

<br />

## Overview

TOTP asks for a code from an authenticator app after you sign in.

<br />

## Features

- Works with any authenticator app
- Backup codes in case you lose your phone
- More than one device
