## Overview

Tailscale pulls the devices on your tailnet into Termix and lets you connect to them with Tailscale SSH, so your tailnet ACLs handle access.

<br />

## Features

- Add tailnet devices as hosts in a couple of clicks
- Connect with Tailscale SSH, with no credentials stored
- Works with Headscale
- A Tailscale card in Host Metrics
